## 通用规则

本地地址 `http://127.0.0.1:8080`，Swagger `/swagger-ui/index.html`，健康检查 `http://127.0.0.1:8081/actuator/health`。普通JSON成功HTTP200，外层 `{code:"OK",message:"成功",data:...}`；文件下载直接返回二进制。分享读取有两项匿名例外，其余公开接口需要身份。

本地老人身份头 `X-Mock-Actor-Id: u100`、`X-Mock-Actor-Role: ELDER`。userId仍是业务归属参数；身份头不会自动填query或body。此机制仅用于本地演示，不是上线认证。

请求字段表中的“条件必填/可选”不是允许任意省略；首次建档、文本/附件二选一、位置说明等条件以本接口备注为准。缺少参数400、无身份401、无权限403、不存在/不可见404、版本/状态冲突409，上游失败可能502。不要把业务code当HTTP状态码。

## 链路一：游览主链路

老人本人：建档 → 查景点和路线 → 看地图 → 开始游览 → 上报进度 → 结束游览 → 反馈和记录。改线、附件、偏好确认与分享是按需分支。保存routeId、tripId和最新progressSeq；Profile.id不能代替userId。

### API-02 PATCH /api/v3/profile

首次建档或修改部分字段。调用者：老人本人。

| 参数 | 位置 | 必填 | 说明 |
|---|---|---|---|
| userId | query | 是 | 业务所属老人，例如u100； |
| X-Expected-Profile-Version | header | 否/按身份场景 | 档案条件版本；更新取GET版本，新建可传0；格式：int64 |

请求正文：`application/json`。

| 字段 | 类型 | 必填 | 限制与含义 |
|---|---|---|---|
| nickname | 字符串 | 条件必填/可选 | 老人称呼；最少字符：0；最多字符：100 |
| age | 整数 | 条件必填/可选 | 年龄；格式：int32；最小：1；最大：150 |
| residence | 字符串 | 条件必填/可选 | 居住区域；最少字符：0；最多字符：200 |
| language | 字符串 | 条件必填/可选 | 交流语言；最少字符：0；最多字符：50 |
| walkSpeed | 字符串 | 条件必填/可选 | 步行速度档位；可选：SLOW、MEDIUM、FAST |
| walkDurationMin | 整数 | 条件必填/可选 | 可接受步行分钟数；格式：int32；最小：1；最大：1440 |
| avoidSteps | 布尔值 | 条件必填/可选 | 尽量避台阶的偏好 |
| interests | 数组：字符串 | 条件必填/可选 | 兴趣列表；最少项：0；最多项：30 |
| interactionPreference | 字符串 | 条件必填/可选 | 文字或语音交互偏好；可选：VOICE、TEXT |
| emergencyContacts | 数组：profile.ProfileFields.EmergencyContact | 条件必填/可选 | 紧急联系人列表；最少项：0；最多项：10 |


成功返回：外层 `{code,message,data}`，data为 **profile.ProfileView**；非空模型的完整字段见字段附录同名模型。

注意：首次建档必须提供全部十项业务字段；后续只传修改项，至少一项。未知字段、显式null拒绝，数组整组替换。可选请求头X-Expected-Profile-Version：新建传0，更新传GET返回的version；过旧409。不传仍兼容，但没有旧页面冲突保护。响应增加version/createdAt/updatedAt；历史时间未知可为null。
