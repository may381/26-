# P2 接口字段附录 v3.0

更新日期：2026-10-29。与《P2后端接口文档_v3.0.md》的01～28业务操作对应。字段按现有业务契约整理为v3开发目标，实施时由v3 OpenAPI和运行校验保持一致。

先看正文的调用步骤，查某个字段再翻本附录。请求中的“未标必填”不代表所有情况都能省略：例如首次建档十项必填、求助位置二选一，按正文业务条件处理。所有响应外层都有code、message、data，下面只展开成功时的data。数组中的[]表示每一个元素。时间为ISO 8601日期时间，建议按用户所在时区显示。

所有公开接口都需要身份头；userId、路径ID和幂等Key的必填情况分别列出。不能把可选query与必填body字段混为一谈。

## 01 PATCH /api/v3/profile

**路径、query和额外请求头**

| 名称 | 放哪里 | 必填 | 怎么填 |
|---|---|---|---|
| userId | 问号后的参数 | 是 | 业务老人ID，例如u100；不是档案UUID；见正文业务说明 |

**请求正文：application/json**

| 字段 | 类型 | 必填 | 说明 / 限制 |
|---|---|---|---|
| nickname | 字符串 | 未标必填 | 老人昵称；最少字符: 0；最多字符: 100 |
| age | 整数 | 未标必填 | 年龄；最小: 1；最大: 150 |
| residence | 字符串 | 未标必填 | 居住地；最少字符: 0；最多字符: 200 |
| language | 字符串 | 未标必填 | 使用语言；最少字符: 0；最多字符: 50 |
| walkSpeed | 字符串 | 未标必填 | 步行速度档位；可选：SLOW、MEDIUM、FAST |
| walkDurationMin | 整数 | 未标必填 | 可接受步行分钟数；最小: 1；最大: 1440 |
| avoidSteps | 布尔值 | 未标必填 | 是否尽量避台阶；见正文业务说明 |
| interests | 数组 | 未标必填 | 兴趣列表；最少项: 0；最多项: 30 |
| interactionPreference | 字符串 | 未标必填 | 文字或语音交互偏好；可选：VOICE、TEXT |
| emergencyContacts | 数组 | 未标必填 | 紧急联系人列表；最少项: 0；最多项: 10 |
| emergencyContacts[].name | 字符串 | 是 | 名称/姓名；最少字符: 0；最多字符: 100 |
| emergencyContacts[].phone | 字符串 | 是 | 联系电话，演示用假数据；最少字符: 0；最多字符: 40 |
| emergencyContacts[].relation | 字符串 | 是 | 与老人的关系；最少字符: 0；最多字符: 100 |

**成功返回：data为对象。**

| 字段 | 类型 | 含义 / 限制 |
|---|---|---|
| data.id | 字符串 | 当前对象的ID，具体是哪个ID见正文对应接口 |
| data.nickname | 字符串 | 老人昵称 |
| data.age | 整数 | 年龄 |
| data.residence | 字符串 | 居住地 |
| data.language | 字符串 | 使用语言 |
| data.walkSpeed | 字符串 | 步行速度档位；可选：SLOW、MEDIUM、FAST |
| data.walkDurationMin | 整数 | 可接受步行分钟数 |
| data.avoidSteps | 布尔值 | 是否尽量避台阶 |
| data.interests | 数组 | 兴趣列表 |
| data.interactionPreference | 字符串 | 文字或语音交互偏好；可选：VOICE、TEXT |
| data.emergencyContacts | 数组 | 紧急联系人列表 |
| data.emergencyContacts[].name | 字符串 | 名称/姓名；最少字符: 0；最多字符: 100 |
| data.emergencyContacts[].phone | 字符串 | 联系电话，演示用假数据；最少字符: 0；最多字符: 40 |
| data.emergencyContacts[].relation | 字符串 | 与老人的关系；最少字符: 0；最多字符: 100 |
