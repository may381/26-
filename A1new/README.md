# 时光链统一问答前端

参考提供的“时光链”五张设计图，以对话页为主体，整合总智能体、旅游和反诈问答。新版独立存放于 A1new，不覆盖原前端。

## 立即预览

双击 start.cmd，或在 PowerShell 执行：

```powershell
cd "D:\desktop\26挑战杯\A1new"
python server.py
```

打开 http://127.0.0.1:8095/ 。手机尺寸在浏览器 F12 的设备工具栏中查看。关闭终端会停止服务。

在家可以查看页面、领域切换、快捷问题、图片选择预览、字号与本页历史。未连接学校模型时不生成虚假回答。主页面没有预置用户聊天、虚构距离或已完成的服务记录。

## 真实调用关系

- 综合 → a1-orchestrator/DomainChat → 学校模型规划 → 现有领域服务。当前总智能体只支持单步旅游/反诈，跨A2/A3任务仍明确不可用。
- 出行 → Java旅游服务 http://127.0.0.1:8091/api/agent/messages → 学校模型。
- 防诈 → Python反诈服务 http://127.0.0.1:8000/api/analyses → 轮询结果。受理和分析完成分开展示。
- 图片 → 旅游 /api/a1/images/analyze 或反诈 /api/image-analyses，按当前领域选择。图片最大4MB，PNG/JPEG；图片问题最多1000字。
- 语音输入是浏览器可选转写，不是学校模型ASR；不支持时明确提示。转写文字需用户确认发送。

统一服务器只依赖 Python 标准库，无需 npm。真实领域调用还需要启动原有旅游、反诈后端；反诈旧虚拟环境问题仍需另行修复。离线看界面无需启动它们。

## 当前边界

仅实现问答前端，不提供健康/照护等其他人的未接通功能；底部移动导航仅保留新对话、对话、记录三个可用动作。对话历史和上传预览只保留在页面内存。A1协调会话保留在本机服务器内存，闲置一小时清理，服务器重启后消失；无生产登录，不对外网开放。图片和文本会按用户发送操作提交给已有服务。

这是统一问答演示入口，不是P2 v3正式任务网关，也没有伪造家属通知、长期记忆或求助处理。
