# P2 接口字段附录 v3.0

更新日期：2026-11-07。对应三条链路的65项公开操作。按模型名称查字段，与接口重排后的编号无关。

模型名称只用于查表，不作为JSON字段发送。引用模型应展开为对象；数组逐项使用其元素模型。请求必填来自OpenAPI及代码条件补充；响应中的required空集合不表示字段一定不返回，也不意味着字段一定非空。动态JsonNode/Map不能从Swagger自动得出完整字段，下文单独说明。

## 动态返回：不要把空Schema当成没有字段

### Agent任务详情 data

字段包括taskId、conversationId、sourceMessageId、parentTaskId、relatedTaskId、version、status、phase、reply、inputRequest、error、createdAt、updatedAt、expiresAt、results、confirmationIds、childTasks、pendingInputRequests、effects。恢复时还可能包含resumeReason、inputResponse等。任务状态为QUEUED/RUNNING/WAITING_INPUT/WAITING_DEPENDENCIES/WAITING_CONFIRMATION/SUCCEEDED/PARTIALLY_SUCCEEDED/FAILED/CANCELLED/EXPIRED；执行情况以实际任务状态为准。reply用于展示，effects记录P2已经执行的事实，两者不能互相替代。

inputRequest/pendingInputRequests中的问题包含inputRequestId、ownerTaskId、version、question、requiredFields、options、allowFreeText；options元素为id/label/value。回答时只引用服务端返回的归属和版本；问题ID由Agent程序生成，P2登记版本。子问题答案恢复对应owner，不改变其他独立子任务。

### 本人任务列表 data[]

taskId、conversationId、status、version、createdAt、updatedAt。只返回最近根任务，最多100项。

### 会话历史 data[]

messageId、taskId、role(user/assistant)、text、createdAt、attachmentIds。时间倒序；失效助手文本替换成提示。

### 调用记录 data[]

invocationId、agentId、baseTaskVersion、state、deadlineAt、createdAt、updatedAt。state是P2本地调用状态；不要与业务任务状态、Agent端收据状态混用。

### 确认详情和决定返回 data

confirmationId、ownerTaskId、rootTaskId、actionId、state、version、actionStatus、expiresAt、canRetry、lastError、operation、summary。公开视图不返回原始args/tool/result；参数由服务端冻结，用户通过summary核对。expectedVersion来自这里的version。当前canRetry=false，不自动重复未知外部操作。

### 共享记忆列表 data[]

当前候选payload包含category/key/content/value/domains/sensitivity/sourceRefs；生效列表补充memoryId、version、confirmedAt。sourceRefs当前仅支持USER_MESSAGE来源。GENERAL长期偏好支持ADD/查看/删除，MERGE/REPLACE和敏感记忆未开放。memoryId/version用于删除，不使用档案version。

### Agent工具/结果

内部工具返回actionId、effectId、tool、executionStatus、businessRef、replayed、result。当前只读业务工具effectId和businessRef为null。result按注册业务模型返回对象或数组；Agent不可自行伪造执行事实。MEMORY_REVIEW是当前可接的结构化卡片；更多旅游/反诈卡片仍需实现，不能按协议规划直接当作已支持。

## 关键空值与文件规则

旧档案createdAt/updatedAt可以null；无景点介绍description=null；尚未上报游览进度data可为null；未生成回复reply=null；mock模式语音合成audioUrl=null。文件读取返回字节，不套JSON。删除成功仍为HTTP200，data=null。
