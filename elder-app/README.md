# 时光链 · 老人端交互原型

使用 uni-app + Vue 3 实现最初五张参考图：首页、服务、对话、记录、我的。尚未实现新增的三个景区路线页。

## 启动

```sh
npm install
npm run dev:h5
```

电脑访问 http://localhost:5190 。手机与电脑连接同一 Wi-Fi 后，访问 `http://电脑局域网IP:5190`（需要防火墙允许该端口）。

## 编译

```sh
npm run build:h5
npm run build:mp-weixin
```

H5 产物：`dist/build/h5`。小程序产物：`dist/build/mp-weixin`，在微信开发者工具导入并配置自己的 AppID。未验证原生 App 打包。

## 可交互内容

- 五页底部导航；首页问题跳转对话，喝水打卡保存本机。
- 服务关键词搜索、无结果提示；记录分类筛选、记录详情。
- 文字模拟对话、对话历史；语音按钮明确显示模拟提示。
- 我的页面各入口弹窗；大字号、慢语速偏好、分项授权本地保存。
- 档案、家属、会员等非本次页面范围入口以弹窗展示，不创建额外业务页面。

## 数据与边界

所有用户、日期、健康记录、消息、距离和统计都是参考图中的演示数据，不代表实时信息。本地存储用于保留聊天、打卡与设置；不会调用后端、定位、录音或向家属发送通知。设置内的慢语速仅保存偏好，未接语音合成。

图片裁切自用户提供的参考图；品牌标志来自工作区现有 SVG。界面通过自适应宽度、窄屏规则、安全区和滚动布局兼容手机；桌面呈现居中的手机内容宽度。

## 目录

- `src/pages/`：五个 uni-app 页面入口。
- `src/components/AppScreen.vue`：页面内容、模拟数据与交互。
- `src/components/screen.css`：共享视觉与响应式样式。
- `src/static/`：本地图片、图标与标志。

当前机器的依赖复制自工作区已有项目；源代码不依赖该旧项目。新机器可运行 npm install 独立安装。

## 景区路线流程

新增景区详情、路线推荐、路线确认三页。首页出门走走/公园推荐、服务智能出行、对话公园卡片可进入。支持三条模拟路线选择、确认页数据同步、偏好修改本地保存、收藏与返回。本次仅做到路线确认，开始按钮仅提示未接入，不创建进行中的游览。地图、时长、设施数均为演示数据。

## 游览主线扩展

路线确认后可进入游览进行中、设施查询、疲劳与路线调整、求助进度。所有定位、时长、接单状态均为本地模拟；不会实际定位、呼叫或通知。确认缩短路线后，本机保存调整状态并回到游览页。设施支持分类与搜索。语音讲解与导航以提示承接，未接入真实服务。

## 游后闭环

游览进行中底部内容区可点击结束本次游览，确认后进入游览完成页。保存并反馈后记录写入本地，在记录页显示本次游览记录。反馈可跳过；长期推荐偏好仅在主动勾选并提交时写入，可在我的档案删除。照片可预览；语音为演示入口；分享复制小结，由用户自行选择分享对象。未接真实后端。

游览进行中入口已按结束入口优化版调整：底部固定结束游览与找人帮忙；地图下方为我累了卡片。结束需二次确认，取消不结束，确认进入游览完成。
