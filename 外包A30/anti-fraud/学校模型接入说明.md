# 反诈骗模块接入说明

继续沿用安知React页面和FastAPI后端。新增school提供方，固定使用学校qwen3.8-27b，无需SSH密码/API Key。保留原Ollama模式。

启动：双击start-school-backend.bat；另一个终端进入anti-fraud运行npm run dev，访问http://127.0.0.1:5174。需要校园服务器网络可达，原Python虚拟环境已存在时可直接使用。

本轮适配文本分析，不依赖学校尚未验证的JSON Schema输出参数；程序仍校验JSON、证据和案例引用，拒绝截断输出。学校图片能力尚未验证，明确阻止该路径；语音仍依赖原本机Whisper转写，不是学校模型语音识别。

当前历史风险摘要是本模块SQLite数据，不是A3共享长期记忆；本地登录/监护人通知不构成生产鉴权/真实短信。本模块尚未接入P2 v3任务和结果卡片，不应把分析记录当作已报警或通知。

后续：先验证学校文本生成，再提供供A1调度的分析接口适配；业务持久化、授权、通知最终对接P2。原有数据库保留，未迁移、未清空。
