# 安知 · 多模态反诈智能助手

React 18 + TypeScript + Vite 前端，配套 FastAPI + SQLite 本地后端与 Ollama 模型。

当前开发进展与启动方法见：[第一阶段文本分析使用指南](./项目方案/第一阶段文本分析使用指南.md)。先启动 Ollama，再运行 `start-backend.bat`，最后启动前端。文本与图片调用本机 `qwen3.5:4b`；语音由本机 Faster-Whisper 转写后进入同一风险分析链路。

开发基线：[项目功能与技术实施方案](./项目方案/项目功能与技术实施方案.md)，包含多模态识别、监护人闭环、数据模型、接口、里程碑及验收清单。当前完成情况以[当前功能实现清单](./项目方案/当前功能实现清单.md)为准。

完整要求对照、页面实现、正式版本方案、测评与提交清单见：[项目要求与功能实现总方案](./项目方案/项目要求与功能实现总方案.md)。

## 启动

需要 Node.js 20.19+ 或 22+。

```bash
npm install
npm run dev
```

生产构建：`npm run build`。预览构建：`npm run preview`。

首次打开进入登录页。也可以访问 `/#login` 单独预览登录页；已登录后访问 `/#dashboard` 进入仪表盘。侧栏“退出登录”可体验登录/注册，输入任意合法 11 位手机号，验证码为 `123456`。注册后跳转角色设置，登录后跳转仪表盘。

## 演示流程

1. 智能助手选择“投资诈骗”或“AI语音诈骗”，自动填入对话并产生本地预警。
2. 风险面板显示类型、模拟置信度、建议；点击通知监护人追加模拟短信日志。
3. 预警中心查看详情、筛选或批量处理。
4. 点击生成报告，选择日期与报告类型，查看三类图表，导出 JSON 或打印保存 PDF。
5. 角色设置管理默认监护人并保存；大字号开关即时全局生效。
6. 知识库粘贴内容或导入 txt/json/csv，清洗、去重并把正文保存到 SQLite。
7. 后端预警可记录监护人联动日志；短信投递仍为明确标注的本地模拟。
8. 知识库支持搜索、编辑、删除和检索测试；预警支持监护人处置反馈。
9. 测评中心内置20条黑白样本，支持规则基线与真实模型评测、指标计算和结果导出。

## 目录

- `src/components`：布局、通用模态框、风险详情、图表。
- `src/pages`：仪表盘、智能助手、预警中心、安全报告、设置、知识库、登录。
- `src/data/mockData.ts`：场景、预警、知识库和图表模拟数据。
- `src/types/index.ts`：共享类型。
- `src/context/AppContext.tsx`：全局设置、预警、通知日志、报告、知识库状态及持久化。

## 能力边界

真实模式已接后端、本地文本模型、图片分析、Faster-Whisper 语音转写，以及至少两种输入的统一多模态融合；无生产鉴权、真实短信、独立语音深伪检测。多模态模拟页保留四种可控演示场景。仪表盘检测数、风险数、评分和七日趋势由当前预警动态计算。角色与风险偏好会作为辅助上下文进入模型，但不能替代本次证据。报告创建后在后端保存当时的事件和统计快照。

localStorage 使用 `anzhi-` 前缀保存设置、模拟预警与登录状态。真实预警、监护人联动日志、自建知识案例、BGE-M3 向量分块、评测记录和报告快照保存在 `backend/data/anzhi.db`。上传图片只用于当次推理，不保存原图；上传音频转写后立即删除原文件，只保存转写文本和时间片段。Whisper 模型位于 `D:\WhisperModels\faster-whisper-base`。

移动端支持抽屉导航；模态框支持 Escape、键盘焦点约束与恢复；大字号设为根字体 19.2px（默认 16px）。
