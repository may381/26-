# A1 合并到 P2 后端：最小清单

## 必须带入

- `a1-orchestrator/` 源码（排除 `__pycache__/`、`.a1-service-key`、`a1-receipts.sqlite3`）。
- `requirements.txt` 中固定的 `langgraph==1.2.20`。
- P2 环境变量：`AGENTS_MODE=http`、`AGENT_A1_URL`、`AGENT_A1_API_KEY`。
- A1 环境变量：`A1_SERVICE_KEY`；调用学校模型时可配置 `A1_MODEL_URL`、`A1_MODEL_NAME`。

`AGENT_A1_API_KEY` 必须等于 `A1_SERVICE_KEY`。密钥不得提交仓库。

## 跨电脑联调

1. 在 A1 电脑运行 `启动A1联调服务.ps1`，输入双方约定的密钥。
2. P2 的 `AGENT_A1_URL` 填 A1 电脑可达的局域网/虚拟局域网地址，例如 `http://10.248.255.85:8093`。
3. 从 P2 电脑访问 `GET <AGENT_A1_URL>/health`。
4. 启动 8091 真实旅游服务，再运行 P2 的 `smoke-a1.ps1`。
