# 接入学校模型

调用关系：浏览器 → a1-guide Java 后端 → 学校 qwen3.8-27b。
不经过 Python A1 的 8093 接口；当前旅游模块可以独立使用学校模型，后续再接总调度。

在可访问校园内网的电脑运行：

    powershell -ExecutionPolicy Bypass -File .\start-school.ps1

打开 http://127.0.0.1:8091/ 。先停止原有占用 8091 的服务后再启动。

配置：AI_MODEL_PROVIDER=school，OLLAMA_MODEL=qwen3.8-27b。
学校地址固定为 http://10.138.50.151:8000/v1/chat/completions；当前文档无 API Key，不使用 SSH 密码。
原 start.ps1 仍默认使用 Ollama；不要在同一终端遗留 school 环境变量后误认已切回本地。

已适配：聊天、基于证据的景点讲解、攻略地点抽取。关闭 enable_thinking，不把内部推理展示给用户；仅解析完整 stop 响应及 JSON answer/places。
尚未因此实现：真实课程/酒店预订、P2任务协作、A3长期记忆；行程地点与交通真实性仍取决于地图服务和数据源配置。模型切换不会自动把 mock 数据变成真实数据。

如不在校园内网，调用可能超时；必须先具备学校授权的网络访问条件。此修改不会自动迁移前端到服务器，不能用服务器 localhost 代替电脑上的 localhost。

验证：在页面发送普通问候及景点讲解，模型失败应明确报错；再导入一段包含明确城市地点的攻略。实际学校连通性需在使用者环境验证。
