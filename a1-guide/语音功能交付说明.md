# 本地语音交付说明

本轮使用 Windows 已安装的中文离线识别器和 Microsoft Huihui Desktop 中文语音，不使用云语音接口。Java 通过适配器调用本地 Python/PyAV 和系统语音，后续可由 P2 替换实现，接口保持契约路径。

## 使用
打开 http://127.0.0.1:8091/?v=speech-live1
点击“点击说话”，允许麦克风，点击“结束录音”；最长30秒。识别结果先填入输入框，核对后发送。回答旁点击“听这段”，播放器可暂停、继续、拖动进度。使用回答中的 speechRate 合成。
浏览器录音需要 HTTPS 或 localhost 安全上下文；手机访问电脑的普通 HTTP 局域网地址不保证可录音。当前只验证本机开发链路，uni-app 真机录音还需 P1 适配。

## 接口
POST /api/speech/transcriptions：multipart file，返回 data.text。
POST /api/speech/syntheses：text、speechRate(0.5—1.5)，返回 data.audioUrl。
GET /api/speech/audio/{id}：WAV，内存最多20段，每段10分钟后不可取，服务重启清空。
问答返回 audioUrl 仍为 null，不改变 A1 契约。页面按需调用合成接口。

## 验证与限制

公开中文样例未识别出内容；尚未真人麦克风/噪声环境验收。不能把合成音频回环测试当成老人实际识别准确率。
Whisper下载失败，当前没有使用Whisper。系统识别能力可能较弱，保留打字和核对流程。
当前没有方言、声音克隆、自动到达讲解、后台持续监听；不会自动发送识别结果。
临时录音/合成工作文件处理结束删除；测试音频为程序合成，不是用户录音。
