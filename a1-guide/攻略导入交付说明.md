# 攻略导入（2026-10-28 更新）

预览：http://127.0.0.1:8091/?v=guide-link1

输入框上方「导入攻略」或加号菜单进入。粘贴小红书笔记链接、xhslink.com / xhslink.cn 分享短链接、正文，或上传截图。

## 链接流程

- 点击「读取攻略并提取」后，先请求公开笔记网页，再提取正文中的目的地和地点。来源卡显示原笔记入口、读取时间和是否真正取得正文。
- 仅接受明确列出的 HTTPS 小红书主域和分享域；每次跳转重新校验，最多5次请求、总计约30秒，正文响应最多2MB。成功结果在内存缓存5分钟，最多32条，失败不缓存。不发送浏览器 Cookie、不执行网页脚本、不访问任意网址。
- 解析页面笔记状态或结构化文章正文；分享标题、网页元描述和登录页不作为完整攻略。避免把其他推荐笔记的正文当成当前笔记。
- 登录、失效、读取失败：明确 NEEDS_CONTENT，提供补充正文、上传截图入口。如果分享文案有文字，可选择「仅提取已粘贴的文字」。
- 名称可以修改、补充，每次最多8个；填写城市后查询高德候选名称与地址，手动确认真实地点。修改城市或名称后会清空对应旧匹配。
- 确认后进入日期、同行与体力问答；后端使用已确认的地点ID生成行程时间轴和地图草案。

## 截图与正文

截图支持 PNG/JPEG、最多4MB、边长不超过5000像素且总像素不超过1600万。使用本机 Windows OCR，识别文字可修改后再交给本地模型提取。临时图片与识别文件处理后删除。

正文最多6000字，模型提取名称必须存在于输入原文。当前地图行程仍使用高德国内地点数据，海外攻略可提取文字，但不承诺海外地点匹配或跨国规划。

## 接口

- POST `/api/a1/guide-imports/read-link`：JSON `url`，返回 READY / NEEDS_CONTENT、text、title、sourceUrl、retrievedAt、message。
- POST `/api/a1/guide-imports/analyze`：JSON `text`，返回 USER_CONTENT、目的地、地点名称和 REVIEW / NEEDS_CONTENT。此接口只分析收到的文字，linkFetched=false；页面读取状态以read-link结果为准。
- POST `/api/a1/guide-imports/ocr`：multipart `file`，返回识别文字与截断标记。

这些是 A1 演示扩展；不将攻略正文写入长期记忆。

## 验证与限制

解析测试覆盖真实正文结构、结构化文章、登录页与分享标题拒绝、错误笔记拒绝、URL白名单与长度限制；正文提取和真实高德地点查询可继续进入行程。

实测截图中的短链接：一次返回 READY 并读到公开笔记正文，其他请求遇到登录或读取限制，说明平台响应并不稳定。正文提取实测返回阳江及海陵岛、十里银滩、大角湾。84项后端测试通过。公开笔记是否可读取取决于平台实际响应；当前没有浏览器视觉或手机点击实测。
