# 语音优化（2026-10-28）

预览：http://127.0.0.1:8091/?v=voice-better1

## 已完成

- 回答分段朗读，每段最多220字符；先播放当前段，同时准备下一段。过滤朗读中的Markdown、链接和表情符号，避免长回答超过接口上限。
- 暂停、继续、停止、原生音频进度控制、0.7至1.3倍语速。语速选择本机保存；「说慢一点」直接改变播放速度。
- 停止后丢弃迟到的合成结果；切换回答、开始录音、离开页面时清理播放和录音资源。
- 录音倒计时30秒，支持浏览器可用的webm/mp4/ogg格式；增加降噪和回声消除请求，实际支持由浏览器决定。
- 识别文字追加到已有输入，不自动发送。识别期间可以停止，权限、设备缺失、录音过短、超时有明确提示。
- 语音合成与识别分开限流，合成音频短时复用，避免同文重复合成。识别优先采用本地 Paraformer 中文模型，空结果要求重录。模型不可用时才使用 Windows 兼容识别。

## 验证

86项后端测试通过；7项音频/候选纠正测试通过；JavaScript回归覆盖长文本分段、Unicode边界、取消后不误播放、暂停/继续。

真实本机接口短句：首次合成约1.62秒，缓存复用约8毫秒，返回有效WAV。用该合成音频调用识别接口成功返回文字和约0.55置信度。该测试不能代表真人或嘈杂环境的准确率。

## 识别准确率优化

- 已安装并启用 sherpa-onnx 1.13.8 / Paraformer 中文小模型 INT8（约82MB），原始文件SHA256已与模型发布者提供值比对。录音在本机处理。
- 输入统一为16kHz单声道，去除直流偏移、裁剪首尾静音、保守调整过低音量；纯静音不会交给识别器。
- 同音地名候选来自当前选中地点和当前行程，使用拼音匹配。原识别结果不自动替换，用户点击确认后才更改。例如当前行程已有海陵岛时，可提示「海领导 → 海陵岛」。
- 实际测试：普通短句中旧服务的「行安排」在新模型中识别为「请安排」；FunASR公开中文语音样本识别为「欢迎大家来体验达摩院推出的语音识别模型」。旅游地名仍会产生同音字错误，不能宣称已全面消除。
- 新环境需要在 speech/vendor 安装 sherpa-onnx==1.13.8、pypinyin==0.55.0；当前复用 ../local-asr/.venv 的 Python、numpy、av。模型和依赖已落地于本机，忽略Git提交。
- 模型源：https://huggingface.co/csukuangfj/sherpa-onnx-paraformer-zh-small-2024-03-09
- 模型SHA256：3ef6c19369b912f7caf3cef8e545c5ccd1a33d9d7ec792a46668dc41c4b229ec
- 下载工具 speech/download_verified.py 支持分段续传与发布者SHA256校验。

尚未进行浏览器、手机麦克风和听感人工验收。本轮沿用本机已安装的Windows中文音色，未引入新的自然人声模型或云端语音服务。声音自然度需另行结合音色/引擎改善。
