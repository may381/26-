# 参考图功能验收清单

本文件用于逐项验收。构建通过不等于视觉或手机验收通过。

| 功能 | 现有状态 | 后续主导/依赖 | 验收条件 |
|---|---|---|---|
| 手机聊天、输入展开、导航收起 | 已编码；待真机 | P1 | iOS/Android键盘不遮挡，返回不丢状态 |
| 录音识别、朗读 | 本机接口实测；真人待测 | P1/P2/A1 | 老人真人录音→核对→回答→播放/暂停 |
| 日期与偏好卡片 | 已编码；接口已测 | A1/P1 | 改日期、切月份、取消、提交均正确 |
| 真实景点与照片 | 高德实测 | P2 Provider/P1 | 无图、空结果、错误与来源均可见 |
| 草案生成 | 初步按查询顺序分配 | A1/P2 | 不宣称最优路线；待接路线约束 |
| 草案添加、删除、排序、保存、恢复 | 已编码；保存恢复实测 | A1适配→P2 | 刷新与服务重启可恢复，用户隔离 |
| 地图全屏与周边分类 | 静态图与分类已接入 | P1/P2 | 待替换交互地图、点击标记和路网线 |
| 天气 | 实况与近期预报已实测 | P2/A1 | 显示发布时间；范围外不编预报 |
| 步行/驾车/公交对比 | 三种方式已实测返回；待手机验收 | P2 | 每种方式独立成功/失败，不伪造费用 |
| 航班动态、票价 | 未配置 | P2/外部供应商 | 用户申请授权Key，验证覆盖与费用 |
| 住宿交通手动记录 | 未实现 | P1/P2 | 明确手填与已核验，支持修改 |
| 网页检索与历史知识核验 | 未实现 | A1/内容来源 | 保存来源、时效、关键事实核查 |
| 正式Trip、路线优化 | 未对接 | P2 | 约束筛选、老人确认、同一tripId |
| 停止生成与流式阶段 | 未实现 | A1/P1 | 实际取消请求与真实工具进度 |
| 手机视觉与触屏验收 | 未完成 | P1 | 全状态截图、触控和键盘验证 |

独立新增接口均为 /api/a1/* 演示适配，合并时与P2确认，不擅自修改底座契约。
草案本地文件位于 a1-guide/data/travel-drafts，HttpOnly 随机浏览器凭据隔离，仅供本机开发。正式上线要迁入团队认证/授权/数据库，不把它当成完整账号系统。
