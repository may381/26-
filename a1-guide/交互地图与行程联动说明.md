# 交互地图与行程联动

预览：http://127.0.0.1:8091/?v=interactive-trip1

在对话中创建出游草案，点击查看计划。地图使用高德 JS API 2.0，支持拖动、缩放和查看全部地点。

- 日期页签切换当天地点编号和实际查询到的步行路线；总览显示全部地点。
- 点击地图编号，高亮并滚动到对应行程项；点击行程的地图定位，收起抽屉并定位地点。
- 拖动抽屉把手可切换高度，也可直接点击展开或收起。
- 查询失败明确提示；未返回的路线不以直线代替。
- 地点编辑、移除、调整顺序与草案保存沿用原有接口，不会创建正式旅程。

高德 JS Key 在本地配置中，安全密钥仅在后端代理使用。新增 `/api/a1/map-config` 与 `/_AMapService/**` 为本地演示适配，不修改团队底座契约。

验证：62 项后端测试通过，前端脚本语法检查通过；运行接口成功生成两日草案，并返回首日步行路线的 17 个步骤。页面与配置接口返回正常。尚未完成浏览器渲染和手机触摸验收，不能将接口通过视为视觉验收通过。

当前为 H5 页面。uni-app 小程序上线需由前端适配原生地图组件。步行路线不代表已核实无障碍或老人适配，草案仍按现有候选地点整理，未完成全局路线优化。
