# A1 高德联调与展示（2026-10-27）

入口：http://127.0.0.1:8091/?v=amap-final1
启动：双击 a1-guide/start.cmd。已启动时不要重复启动。

## 展示流程
1. 底部“查询真实地点”，城市填长沙，地点填岳麓山，搜索。
2. 核对结果名称、地址，点击“选择并询问”。卡片照片由高德提供；没有图片时不伪造。
3. 询问“详细讲讲”“几点开门”“这里有什么历史故事”。仅依据返回资料回答，缺失的故事不编造。
4. 点击“在高德查看地图”打开官方地点页，在高德进一步选择路线。这里不是已接入无障碍路线规划。
5. 取消选择可回到原有清风园演示；开始新对话清除本次选择。

## 接口与配置
- GET /api/a1/places?query=岳麓山&city=长沙：独立 A1 展示适配接口，返回 source、retrievedAt、places。
- POST /api/agent/messages：保留原响应字段。context.location 传 amap:POI_ID，tools 中 place.detail 携带 AMAP 证据和地点卡片。
- 原 spot-001 等仍属于 MOCK 演示资料，不能当作真实地点。
- Key 存在 config/amap-local.properties，已加入忽略规则，不要提交、打包共享。也可使用 AMAP_WEB_KEY 环境变量。
- 交给团队 P2 时，将 AmapPlaces 的服务调用迁入平台；前端只调用自己的后端，不接触 Key。
