# 本地合并体验版

这是只保存在本机的合并副本，不包含 `.git`，不会修改或推送 GitHub。

## 已合入的部分

- `admin/`：后台管理前端（从本机 `origin/main` 补回）
- `mobile/`：移动端前端（从本机 `origin/main` 补回）
- `p2-backend/`：P2 Java 后端
- `A1new/`：A1 对话体验页面
- `a1-orchestrator/`：A1 总智能体（LangGraph）
- `a1-guide/`：旅游智能体
- `anti-fraud/`：反诈骗智能体

## 重要边界

- `A1new` 是当前用于查看 A1 三部分联动效果的页面。
- `admin` 和 `mobile` 是原仓库前端，已放进同一目录，但尚未改造成完整调用 P2 v3/A1 接口；不要把“同目录”误认为“接口已全部接通”。
- P2 的数据库集成测试依赖 Docker。必须等 WSL 安装完成、重启电脑并确认 Docker Engine running 后再启动。
- 此副本未复制任何 `.env`、QQ 邮箱授权码、数据库密码或 A1 服务密钥。

## 推荐体验顺序

1. WSL 安装完成后重启电脑。
2. 打开 Docker Desktop，等待 Engine running。
3. 先运行根目录 `全项目合并前自检.ps1`。
4. 启动 P2、A1 总智能体、旅游和反诈服务。
5. 打开 A1 页面并分别测试旅游问题和反诈问题。

JDK 21 路径：

```text
C:\Program Files\Microsoft\jdk-21.0.13.21-hotspot
```

邮件配置需要在本副本的 `anti-fraud/backend/.env` 中重新填写；不要把原授权码复制到文档或提交到 GitHub。
