# 比赛候选版：学校模型统一入口

旅游对话、攻略分析、反诈文本分析和 A1 需求规划统一使用服务器 qwen3.8-27b，地址 http://10.138.50.151:8000/v1。不会自动切换其他模型；在家无法访问校园网络时，模型功能会明确提示连接失败。

双击根目录“比赛启动菜单.cmd”：1 启动旅游，2 启动反诈后端，3 启动反诈前端，4 打开展示入口，6 打开 A1 自然语言领域联通 CLI（非 P2 正式总调度），5 退出。每个服务使用一个窗口，分别打开菜单选择。旅游 8091，反诈后端 8000，反诈前端 5174。先关闭同项目旧服务再启动，避免仍访问旧模型配置。

语音识别、语音合成、知识库向量检索是独立服务，当前仍依赖本机组件，不属于该文本模型接口。学校图片与视频能力未验证，暂时关闭对应分析入口。

新电脑需要 Java 17、Node.js、Python 及项目依赖。前端执行 npm ci，反诈后端安装 backend/requirements.txt。地图密钥单独配置，不在共享包中。SSH 密码不是模型 API Key。

当前是比赛验收候选版；P2 正式网关、共享记忆、真实通知与报名尚未接通。学校模型完整端到端验收仍需在校园网络执行。历史本机模型测试仅作为适配器历史证据，不能作为当前学校模型验收结果。

release-manifest.json 记录发行 JAR 与 SHA256，start-release.ps1 校验后启动。build_delivery.py 仅打包允许清单，排除数据库、密钥和虚拟环境。P2 结果卡片 resultId 正文与 Schema 的冲突仍待后端确认。

## 回校后的真实模型验收

在本机 Windows 终端、项目根目录运行：

```powershell
python 交付文档/school_generation_check.py
```

该脚本只发送合成连通性文字，不创建预警、报名或通知。输出学校模型实际生成验收.json；success 必须为 true，模型名称、HTTP 状态与停止原因同时核验。失败时返回非零退出码。

随后分别启动旅游与反诈，按验收单测试实际页面。反诈后端目录的 local_model_smoke.py 名称为历史保留，现在只调用学校模型；real_api_smoke.py 也只调用学校模型，并使用临时数据库。它们分别写 school-model-smoke-result.json、school-api-smoke-result.json，不覆盖历史本机测试证据。
