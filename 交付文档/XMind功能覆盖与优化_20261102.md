依据：老人数字分身平台｜项目主线重排版_v2(1).xmind。范围：A1 的旅游、反诈与平台交接。学校 qwen3.8-27b 继续作为生成模型。本文件区分本机可用功能、演示资料与需团队接通的能力，不把页面入口视作业务闭环。

## XMind 其他节点的团队归属

健康生活、健康资料与提醒、状态活动推荐和专业转介由 A2 主责；家庭照护分工、主动近况分享、家庭留言、普通社区活动、志愿匹配、服务签到评价时长由 A2 与 P1/P2 协作。非遗展示、课程、学习打卡、技艺发布、学习记录、技能/意愿登记、能力匹配、贡献记录由 A3 主责。时间银行只预留接口，不进行资金或养老金兑换。

共享底座的身份、授权、业务存储、通知与真实状态由 P2 负责；A1 负责统一需求理解、委派与汇总。所有领域的长期记忆都须候选、审核、用户确认、P2 执行。不得把本轮本机偏好或游览记录当作这套流程已完成。

居家智能、认知情绪、数字遗产、机构分身、社会协同网络在 XMind 中属于未来扩展，当前仅保留需求与边界，不新增假办理入口。市场、合作实验点、商业模式和汇报顺序属于验证与材料工作，不能以代码完成替代。

## 页面验收路径

1. 旅游主页：第一次使用 → 保存20分钟与避台阶 → 新建计划，核对对应偏好。
2. 打开计划某日 → 游中记录 → 将首个地点标记已游 → 点“我累了” → 未确认前记录不变 → 确认减少剩余地点，已游及下一站保留。
3. 保存反馈、刷新恢复、复制自报小结，再删除本日记录；不出现已通知或已写入长期记忆。
4. 反诈智能助手：三种操作场景 → 不勾选/部分勾选/全部勾选自查，均不能出现批准付款或安全保证。
5. 查看五类卡片并朗读/停止；无有效家属电话时提示添加，有号码时只提供用户主动拨号。
6. 点真实模式案例模板，核对文本输入框确实填入；已有输入需确认替换，任务处理中不可替换；不自动提交模型。
7. 真实结果详情 → 核对摘要 → 复制；原始聊天、姓名、日志字段不应直接进入摘要。

本轮没有完成上述全部浏览器人工验收，没有验证校园模型连通，也未接通真实 P2/A2/A3。测试与构建结果另见本轮检查记录。
